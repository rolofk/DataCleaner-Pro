# DataCleaner-Pro 🧹

*(English version below)*

**DataCleaner-Pro** es una herramienta de automatización y *scripting* en Python diseñada para simplificar y acelerar los flujos de trabajo de limpieza y preprocesamiento de datos. Este proyecto demuestra la implementación de rutinas eficientes para transformar datos en bruto en información estructurada y lista para el análisis.

## 🚀 Características Principales

*   **Procesamiento automatizado:** Ejecución de rutinas de limpieza mediante *scripts* optimizados, reduciendo la intervención manual.
*   **Limpieza integral:** Algoritmos automatizados para la detección y eliminación de duplicados, y el manejo de valores nulos o atípicos.
*   **Estandarización de datos:** Unificación de formatos y tipos de datos para garantizar la consistencia en grandes volúmenes de información.

## 📋 Requisitos Previos

Para auditar o ejecutar este *script* en un entorno local, se requiere:
*   Python 3.8 o superior.
*   Las dependencias listadas en el archivo `requirements.txt`. Puedes instalarlas usando:
    `pip install -r requirements.txt`
*   **Opción ejecutable (Sin instalación):** Si no deseas instalar Python ni dependencias, también contamos con el archivo ejecutable `main.exe`. Solo debes descargarlo, hacer doble clic y el programa se ejecutará directamente.

# DataCleaner-Pro 🧹 (English)

**DataCleaner-Pro** is a Python automation and scripting tool designed to streamline and accelerate data cleaning and preprocessing workflows. This project showcases the implementation of efficient routines to transform raw data into structured, analysis-ready information.

## 🚀 Main Features

*   **Automated Processing:** Execution of data cleaning routines through optimized scripts, significantly reducing manual intervention.
*   **Comprehensive Cleaning:** Automated algorithms for detecting and removing duplicates, as well as handling null or outlier values.
*   **Data Standardization:** Unification of data formats and types to ensure consistency across large datasets.

## 📋 Prerequisites

To audit or run this script in a local environment, you will need:
*   Python 3.8 or higher.
*   The dependencies listed in the `requirements.txt` file. You can install them using:
    `pip install -r requirements.txt`
*   **Executable Option (No Installation Required):** If you prefer not to install Python or any dependencies, we also provide the `main.exe` executable file. Simply download it, double-click, and the job is done.
